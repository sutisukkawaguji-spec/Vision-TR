โหมดปกติ

ใช้คำสั่งเสียงทั้งหมด ค้นหา เปิดแปลง อ่านข้อมูล บันทึก และจัดการรูปภาพ

โหมดขับขี่ปลอดภัย

เปิดอัตโนมัติแบบเบื้องหลังเมื่อเคลื่อนที่เร็ว พร้อมรับคำถามเรื่องเป้าหมาย ระยะทาง เวลา และคำสั่งยกเลิกนำทาง โดยไม่แสดงป้ายรบกวนหน้าจอ

คู่มือการสั่งการด้วยเสียง (Voice Commands)

คุณสามารถสั่งการระบบด้วยเสียงภาษาไทยหรือภาษาอังกฤษผ่านปุ่มไมโครโฟน โดยมีรายการคำสั่งดังต่อไปนี้

🎤 จัดการเสียง & สแตนด์บาย
  • "ปิดไมค์" / "ปิดไม" / "mute mic": ปิดไมโครโฟนชั่วคราว (ปุ่มจะเป็นสีส้ม)
  • "เปิดไมค์" / "เปิดไม" / "unmute mic": เปิดไมโครโฟนใช้งานอีกครั้ง
📝 การบันทึกข้อมูลแปลง
  • "สำรวจ" / "เปิดบันทึก" / "เปิดกล่องบันทึก" / "เปิดแบบฟอร์ม": เปิดกล่องบันทึกของแปลงที่เลือกหรือแปลงที่กำลังนำทาง และพร้อมพูดบันทึกหมายเหตุต่อ
  • "ขอดูรายละเอียด" / "ดูรายละเอียด" / "show details": แสดงกล่องข้อมูลดิบต้นฉบับของแปลงที่เลือกทันที
  • "เลื่อนลง" / "ลง" / "เลื่อนขึ้น" / "ขึ้น": เลื่อนดูข้อมูลในตารางข้อมูลดิบขึ้น-ลง
  • "อ่านรายละเอียด" / "อ่านบรรทัดที่ [X]" / "อ่านตั้งแต่บรรทัดที่ [X] [จำนวน [Y] บรรทัด / ถึง [Y]]": สั่งให้อ่านรายละเอียดข้อมูลดิบทีละบรรทัด พร้อมไฮไลท์และเลื่อนตามอัตโนมัติ (พูด "หยุด" เพื่อหยุดอ่าน)
  • "บันทึก" / "เซฟ เซอร์เวย์" / "save survey": บันทึกข้อมูลที่กรอกลงระบบ
  • "ปิดกล่อง" / "ปิดรายละเอียด" / "close sheet": ปิดหน้าต่างบันทึกข้อมูล
  • "ลบการบันทึก" / "ลบบันทึก" / "delete survey": ลบข้อมูลผลการสำรวจและคืนค่าสถานะ (แปลงที่ดินยังอยู่บนแผนที่)
  • "ลบข้อความ" / "เคลียร์โน้ต" / "clear note": ล้างข้อความทั้งหมดในหมายเหตุหรือช่องค้นหา
🗺️ ค้นหาและนำทาง
  • "ค้นหาข้อมูลแปลง [คำค้น]": ค้นหาข้อมูลแปลงที่บันทึกไว้ในระบบ
  • "ค้นหาสถานที่ [ชื่อสถานที่]": ค้นหาร้านค้า ที่อยู่ หรือสถานที่บน Google Maps
  • "ค้นหา" / "ช่องค้นหา" / "search": โฟกัสไปที่ช่องค้นหาปัจจุบัน และสามารถพูดคำที่ต้องการค้นหาต่อเพื่อพิมพ์ได้ทันที
  • "เหลือกี่กิโล" / "กำลังไปไหน" / "เป้าหมายคืออะไร" / "อีกนานไหม": แจ้งจุดหมาย ระยะทางคงเหลือ และเวลาโดยประมาณ
  • ขณะขับขี่: "ค้นหาสถานที่ [ชื่อ]": ค้นหาและอ่านผลลัพธ์ 3 รายการแรกให้ฟังอัตโนมัติ
  • "อ่าน 4 รายการ": อ่านชื่อผลการค้นหาตามจำนวนที่ระบุ โดยอ่านได้เท่ากับจำนวนผลลัพธ์ที่มี
  • "เลือกรายการที่ 1": เลือกผลค้นหาตามลำดับ; สำหรับสถานที่จะพาไปแสดงหมุดบนแผนที่
  • "เลือกรายการที่ 1 เดินทาง": เลือกผลค้นหาตามลำดับและเริ่มนำทางทันที
  • "นำทาง" / "เดินทางต่อ": เริ่มนำทางไปยังรายการหรือหมุดที่เลือกไว้ล่าสุด
  • "การนำทางล่าสุด" / "เส้นทางล่าสุด" / "ไปที่ล่าสุด": เริ่มนำทางไปยังจุดหมายล่าสุดอีกครั้ง
  • "ติดตามตำแหน่ง" / "ตามฉัน": เปิดให้แผนที่ติดตามตำแหน่ง GPS ปัจจุบัน; พูด "หยุดติดตามตำแหน่ง" เพื่อปิด
  • ขณะขับขี่: "เลือกรายการที่ 1 เดินทาง": เริ่มนำทางด้วยเสียงทันทีโดยไม่ต้องแตะหน้าจอ
  • "แปลงถัดไป" / "จุดถัดไป" / "next point": นำทางไปยังแปลงสำรวจถัดไปที่อยู่ใกล้ที่สุด
  • "ยกเลิกการนำทาง" / "หยุดนำทาง" / "cancel route": หยุดการนำทางในปัจจุบัน
  • แตะแผนที่สองครั้ง: ปักหมุดเดินทางได้ทุกตำแหน่งโดยไม่จำเป็นต้องมีรูปแปลง แล้วเลือกนำทางในระบบหรือเปิด Google Maps
🖼️ การแสดงผลแผนที่
  • "เปิดป้าย" / "เปิดป้ายชื่อ": แสดงป้ายชื่อหมุดบนแผนที่
  • "ปิดป้าย" / "ปิดป้ายชื่อ": ซ่อนป้ายชื่อหมุดบนแผนที่
  • "แสดงแปลง" / "แสดงรูปแปลง" / "plot mode": สลับโหมดแผนที่เป้นแสดงรูปแปลงขอบเขตที่ดิน
  • "แสดงหมุด" / "ปักหมุด" / "สั่งแสดงหมุด" / "แสดงหมุดแผนที่" / "pin mode": สลับโหมดแผนที่เป้นโหมดหมุดแผนที่
  • "สลับแผนที่" / "เปลี่ยนแผนที่" / "สลับแผนที่ฐาน" / "switch map": สลับชนิดแผนที่ฐานไปมาระหว่างแผนที่ถนนและแผนที่ดาวเทียม
